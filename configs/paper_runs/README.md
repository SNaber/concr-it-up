# Paper-run configurations

This directory contains the eight language-specific configurations reported in
the KNN-ConcrItUp demo paper. `manifest.csv` summarizes the corresponding
resources, sample counts, selected settings, and reported metrics.

The configurations are reproducibility records, not self-contained examples.
Their human-rating resources, target vocabularies, and fastText Common Crawl
models are not distributed with this repository and must be obtained under
their respective licenses. Before rerunning a configuration, update its
repository-relative resource paths as needed and record the versions and
checksums of all external inputs.

Because the configurations use heterogeneous resources and rating scales,
their results should not be interpreted as a controlled cross-language
benchmark.
